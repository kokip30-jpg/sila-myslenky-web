Zásady ochrany osobních údajů

Poslední aktualizace: 20. září 2026

Co tento web ukládá

Web nevyžaduje vytvoření účtu. Uložené články, večerní zápis a malé kroky zůstávají pouze v prohlížeči na tvém zařízení. Neodesílají se na server ani správci webu.

Měření návštěvnosti

Web používá Cloudflare Web Analytics pro souhrnné měření návštěvnosti a rychlosti webu. Služba nepoužívá reklamní cookies ani nevytváří profil konkrétního návštěvníka.

Odkazy na jiné služby

Odkazy na Instagram, Facebook, SimpleShop a Payhip vedou na stránky jiných provozovatelů. Při návštěvě těchto služeb se řídíš jejich vlastními zásadami ochrany soukromí.
